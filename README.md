# Royal Roots Ply India Website

Official website for Royal Roots Ply India Pvt. Ltd., the leading premium plywood, laminates, acrylic, and veneer supplier in Ahmedabad, Gujarat.

## Technology Stack

This website is built focusing on extreme performance, modularity, and SEO without relying on bloated external frameworks. 

- **Languages:** HTML5, CSS3, ES6 Vanilla JavaScript
- **Architecture:** MVVM (Model-View-ViewModel) Pattern
- **Design:** Custom CSS tokens and variables, precise typography (Inter, DM Serif Display)
- **Technical SEO:** Fully implemented JSON-LD structured data (LocalBusiness, FAQPage, Article, Product, ImageGallery), dynamic sitemap, and strict `.htaccess` caching and routing.

## Development Phases

This repository was meticulously developed across 10 structured phases:

1. **Design System:** Custom CSS resets, tokens, typography, layouts, and interactive components.
2. **Components & MVVM Architecture:** Reusable navigation, models, and ViewModels.
3. & 4. **Homepage (`index.html`):** Conversion-optimized, highly interactive landing experience.
5. **Lead Capture Pages:** `franchise.html` and `contact.html` designed for seamless lead generation.
6. **About Page (`about.html`):** Brand storytelling and certification outlines.
7. **Product Pages:** In-depth product showcases (skipped in this iteration via prompt guidance, to be expanded later).
8. **Content & Resources:** `gallery.html`, Knowledge Hub (`resources.html`), and expert blog articles.
9. **Technical SEO Layer:** `.htaccess`, `sitemap.xml`, `robots.txt`, and core JSON schemas.
10. **Production Merge:** Final alignment and stabilization into the `main` branch.
